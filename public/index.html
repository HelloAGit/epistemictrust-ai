Decision utility simulator

Model a binary event with costs from true positives, false positives, and missed events. Values are hypothetical.

The simulator uses expected loss. Taking action costs the stated false-positive amount only if the event is absent; no-action incurs loss only when the event occurs. It does not infer causation or assess real model performance.

Model-based recommendation

Threat 01

Data contamination

The model has seen test items, solutions, or identifiable paraphrases during training or retrieval.

Mitigate with private holdouts
Threat 02

Grader gaming

A model satisfies an automated grader's superficial check without actually performing the requested task.

Mitigate with independent checks
Threat 03

Prompt overfitting

Benchmarks are tuned against a fixed template, hiding fragility across equivalent phrasings.

Mitigate with variants

Demonstrate a scoring exploit
