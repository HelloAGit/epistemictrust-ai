# V2 deterministic preview

Advanced calibration uses binary event probabilities and labels. Classification uses the 0.5 threshold. Brier is mean squared probability error. Log loss clips a working copy at 1e-15 and 1 − 1e-15. ECE weights absolute bin gaps by count and MCE takes the largest gap. Adaptive bins use the starting rank of each probability tie group and keep ties together. AUROC uses tied positive-negative pairs as half credit and is undefined when only one class is present. Risk uses classification error at each retained fraction when ordered by distance from 0.5. The Brier interval uses seeded case resampling and empirical percentile endpoints. It assumes independent sampled cases.

Advanced simulation treats each state probability and payoff as an input assumption. Expected utility is the probability-weighted payoff. Expected regret compares each action with choosing the best action separately for every state. Value of perfect information compares that same state-by-state optimum with the best fixed action. Seeded simulation draws states shared by every policy. Results are scenario estimates. The tool has no observational causal inference component.
